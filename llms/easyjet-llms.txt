# easyJet

> easyJet Airline Company Limited is a British low-cost short-haul carrier flying a point-to-point network of more than 155 airports across 35 countries. Its API posture is commercial-agreement-gated and undocumented: there is no developer portal and no machine-readable contract of any kind. Agency and reseller access to easyJet content runs through fourteen approved aggregator and GDS channels, or through a bilateral Direct API Agreement, governed by a published Distribution Charter. easyJet is not an NDC carrier.

## APIs

- [easyJet Brand Widget Service (easyDom)](https://brand.easyjet.com/en/): The only easyJet integration surface that answers anonymously. A hosted JavaScript widget platform partner and white-label sites embed for easyJet page chrome and for easyJet customer sign-in, registration and visitor recognition. Undocumented; partner-scoped by a `partner` query-string identifier.
- easyJet REST API (api.easyjet.com, b2b.easyjet.com): real production hostnames, entirely Akamai-gated. HTTP 403 on every path probed, including every spec and discovery path. Not listed as a consumable API because nothing is published about it.

## Commercial contract

- [Distribution Charter, version March 2026](https://www.easyjet.com/en/business/distribution-charter): the governing document for all reseller API access. A Reseller may access easyJet Data only via an Approved Channel with an API agreement, or directly via the easyJet API under a Direct API Agreement. Screen scraping and automated extraction are forbidden.
- [Approved channels](https://www.easyjet.com/en/business/approved-channels-): the fourteen approved aggregator and GDS partners, with a nine-capability functionality matrix current to end of May 2026 — Amadeus, Anaxys, Bewotec, Duffel, JFA Systems, Kyte, Paxport, Peakwork, Sabre, Travelfusion, Travelport, Traveltek, Viaxoft, Ypsilon.
- [Travel trade partners hub](https://www.easyjet.com/en/business/travel-trade-partners): the trade-facing landing page. No technical content.
- [Acceptable Use Policy](https://www.easyjet.com/en/policy/acceptable-use)
- [Terms and conditions](https://www.easyjet.com/en/terms-and-conditions)
- [Privacy notice](https://www.easyjet.com/en/policy/privacy)
